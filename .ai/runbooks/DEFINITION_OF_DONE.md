# Definition of Done

- [ ] Requirements understood
- [ ] Current implementation inspected
- [ ] Schema inspected
- [ ] Security boundary defined
- [ ] Minimum implementation complete
- [ ] Database verified
- [ ] RLS/grants/policies verified
- [ ] Positive authorization test passed
- [ ] Negative authorization test passed
- [ ] UI path tested
- [ ] Persistence tested
- [ ] Error path tested
- [ ] Regression checks passed
- [ ] Evidence recorded
- [ ] Project state updated

For production workflows: real authorized testing is required, or the exact missing human dependency must be recorded as BLOCKED/UNPROVEN.
